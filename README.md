# zibuyuweb

「子不语输入法」App Store 上架配套静态页，由 GitHub Pages 托管，无构建、无外部依赖。

- 首页：<https://miaolegemi9527.github.io/zibuyuweb/>
- 隐私政策（App Store Connect「隐私政策 URL」）：<https://miaolegemi9527.github.io/zibuyuweb/privacy/>
- 技术支持（App Store Connect「技术支持 URL / Support URL」）：<https://miaolegemi9527.github.io/zibuyuweb/support/>

## 维护说明

- 隐私政策正文以 App 仓的 `QQInput/PRIVACY.md` 为唯一真源；改动先改真源，再同步本仓 `privacy/index.html` 并更新页面顶部「更新日期」与文末 English Summary。
- 风格与 App 上架图「墨夜极光」一致：深底 + 极光渐变强调色，样式集中在 `assets/style.css`。
- 用户反馈渠道为本仓 GitHub Issues（`support/` 页有入口）。
